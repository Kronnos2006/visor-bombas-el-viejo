# Propuesta de visor de mantenimiento

Este archivo demuestra la descarga de documentos vinculados a una bomba.

P-9001 y P-9002 son activos ficticios para presentar el funcionamiento del sistema. Sus medidas, códigos y registros no deben utilizarse para comprar repuestos, dimensionar equipos ni intervenir maquinaria real.

Recorrido: seleccionar equipo → acercamiento 3D → separar piezas → seleccionar sello u o-ring → consultar ficha → abrir historial → registrar informe de prueba → consultar Gemini con clave API.

Al aprobarse la propuesta se reemplazan los ejemplos por documentación verificada, geometría y piezas del modelo instalado. Los datos reales de Vocatus permanecen en su bóveda original.
